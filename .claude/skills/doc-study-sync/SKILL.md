# Doc Study Sync（文档双轨同步器）

| 源文档目录（事实源） | `docs` |

> 配置表为空或占位符未替换 = 本项目未完成迁移；先提示用户补配置，禁止凭猜测同步。

## 🚦 触发与模式

| 模式 | 触发 | 动作范围 |
|---|---|---|
| 全量初始化 | 首次建立镜像 / 用户说「初始化双轨」 | 逐篇源文档走完整流水线；建 `AutoAiSelfHeal/` 目录与 README |
| 增量同步 | 源文档有新 commit | `git diff` 定位变更篇，只处理变更篇与受影响交叉引用 |
| 单篇同步 | 用户点名某篇 | 只处理该篇 |

## 📜 顶层铁律（先读；违反任何一条立即停止并报告）

1. **事实源唯一性**：源文档是绝对真理。镜像只允许改变表达形式；严禁改变数值、路径、键名。
2. **原子块保护**：正则 `[a-zA-Z0-9_\-/.]+` 的连续串（路径、环境变量、函数名、端点）是不可分割原子；禁止在原子中间加空格、换行或「的」。

## 🔄 强制流水线（按序执行，不得跳步、不得合并）

### 1️⃣ Diff 识别
- 读源文档最新 commit hash；与镜像头部版本印记对比。
- `git diff 旧hash..新hash -- docs` 标记变更段落：新增 / 修改 / 删除。
- 源无变化 → 回报「已是最新」并结束。

### 2️⃣ 冲突熔断
- 镜像数值与源冲突时：**禁止**自行计算、估算或折中。
- 必须输出：`❌ [数据冲突待人工仲裁: 源值X vs 镜像值Y]`，终止本次同步，等人工裁决。

### 3️⃣ 改写执行（翻译官 9 条）

| # | 规则 | 执行逻辑 |
|---|---|---|
| 1 | 断句切分（硬约束） | 以 。！？； 分句。中文自然句超 25 字，用「（即...）」插口语化补丁；连续 3 句超 20 字，插入一句「你可能会问...」打破节奏 |
| 2 | 「的」字死刑（硬约束） | 删结构助词「的」（x的y → xy）；保留「的确」「目的」等非结构助词 |
| 3 | 被动语态猎杀 | 「被」一律改主动句；例外仅项目固定术语（见配置表补充） |
| 4 | 动词复活术 | 「进行/实施/开展+名词」→直接动词（「进行删除」→「删除」） |
| 5 | 虚词过滤库 | 众所周知、显而易见、总的来说、需要注意的是、基本上 |
| 6 | 类比四象限锚定（核心） | 类比必须且仅选自：厨房（幂等=微波炉热剩饭，热几次都一样）、交通（限流=收费站车道数）、快递（消息队列=快递柜暂存）、人体（缓存=短期记忆）。严禁技术术语解释技术术语（如「分布式=多节点协同」红牌） |
| 7 | 面试加餐（红线） | 每内容章节结尾输出「**面试官追问**：<一句话问题>」——基于本段、能自答、深挖方向：为什么不用替代方案 > 边界 > 失败场景 > 取舍 |
| 8 | 豁免区 | 命令、表格、Mermaid 图、链接原封不动搬运；不参与字数与「的」检查 |
| 9 | 事实一致性三重校验 | 改写完回查：①端点路径 ②配置键名 ③数字阈值——与源逐字相同 |

改写原则：只动散文。源变更仅改措辞 → 保留镜像原类比；事实变更 → 废弃旧类比，按四象限重生成。

### 4️⃣ 版本印记
- 镜像文档头部更新：`> 源版本: <源 commit hash> | 同步日期: <UTC，如 2026-08-31T03:20:00Z>`。

### 5️⃣ 事实一致性三重校验（独立于第 3 步再跑一遍）
- 抽取本次触碰的端点路径、配置键名、数字阈值，与源 diff 逐字比对。
- 任一不一致 → 回滚本次镜像改动，回到 2️⃣ 熔断流程报告。

### 6️⃣ 提交推送镜像仓库
- 在 `E:\Project\AutoAiSelfHeal-docs-study` 提交：`docs(AutoAiSelfHeal): 同步 <源hash>（<篇名列表>）`。
- `git push` 到 `https://github.com/Testamentt/docs_study.git`；推送失败（网络/凭据）→ 保留本地 commit，回报用户，不重试超过 1 次。

### 7️⃣ 回报格式
```
同步完成/终止
- 源版本: <hash> → 镜像版本印记: 已更新
- 变更篇: <列表>（每篇: 变更段落 → 改写要点 → 追问新增 N 条）
- 熔断/待仲裁: <无 或 ❌ 条目>
- 推送: <成功/失败原因>
```

## ✅ 输出前自检

- [ ] 镜像与源之间：端点、键名、阈值逐字一致（三重校验通过）。
- [ ] 原子块抽查 5 处：无被拆散、无被插入空格/「的」。
- [ ] 新散文：抽 5 句 ≤25 字；「的」「被」「进行/实施/开展」零残留（豁免区除外）。
- [ ] 新类比全部出自四象限；无术语解释术语。
- [ ] 每个内容章节有且仅有 1 条「面试官追问」。
- [ ] 版本印记已更新且与源 commit 一致。

## ⚠️ 常见失败模式（避免）

- ❌ 跳过 Diff 直接全篇重写 → 措辞变更被放大成事实重写，旧类比被无谓丢弃。
- ❌ 数值对不上时「顺手修正」→ 必须熔断交人工，你可能改错的是源。
- ❌ 把豁免区一起改写 → 表格/命令/Mermaid/链接必须逐字搬运。
- ❌ 追问硬凑 → 无内容可问的章节宁可不加并回报，禁止编问题。
- ❌ 在源仓库里提交镜像 → 镜像只活在 `E:\Project\AutoAiSelfHeal-docs-study` 独立仓库。
- ❌ 源文档不存在/被重命名时静默跳过 → 回报缺失清单，交人工确认映射。
