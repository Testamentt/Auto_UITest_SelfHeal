# 会话沉淀文档模板

> **定位**：变更沉淀五要素模板——复制到 `docs/sessions/YYYY-MM-DD-<主题>.md` 后填写，与代码同批提交。
> **状态**：活文档（模板）
> **最后更新**：2026-11-11 · 关联：[归档区 README](../README.md)（写作约定）

## 用法与边界

- **仅多轮推进的任务**需要沉淀；一次性小任务（改文案、装依赖、小修小补）不需要。
- 文档**不是快照**：随进展同步更新，始终反映最新状态。
- 历史文档只读：写完即冻结在 `docs/sessions/`，后续结论变化写新文档并在 [TODO.md](../TODO.md) 登记。
- 抄送格式：头部三行元信息（定位 / 状态 / 最后更新）按 [归档区 README](../README.md) 的「写作约定」填写。
